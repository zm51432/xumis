shine 星心 · Android App

独立站官方移动客户端，安装即用，无需任何配置。

  • 版本 2.0.0
  • Android 7.0+（含 14）
  • 约 20 MB（含离线资源）
  • 仅 4 项权限
  • 适配小米 / OPPO / vivo
下载安装包（.apk）

如果微信内打不开，请点右上角「在浏览器中打开」

安装步骤

  1. 点击上面的按钮下载 shine-xumis.apk
  2. 在通知栏或文件管理里点开安装包
  3. 如提示「禁止安装未知来源应用」，按提示允许浏览器/文件管理器安装
  4. 打开 App，启动页显示「连接成功」即代表接口已打通

已内置的服务能力（全原生）

  • 首页商品流、分类、搜索、排序（默认按「已售」从多到少）
  • 商品详情：图片、价格、库存、材质、定制标识，支持分享
  • 原生购物车 / 结算下单 / 我的账户 / 我的订单（不再跳网页）
  • 来图定制、询盘联系、找回密码、离线商品册、配送与售后条款（全原生）
  • 「设置」按常规 App 分组：通用 / 内容与存储 / 权限与隐私 / 帮助 / 关于
  • App 内一键升级：静默检查 → 下载 → SHA-256 校验 → 调起系统安装器

版本更新记录

App 在后台直连官方商店服务，安装后不需要填写任何地址或账号信息。 权限可以随时拒绝，拒绝后只有对应功能不可用，商品浏览、搜索、下单等核心流程照常。
安装后，后续版本都会在 App 内提示并一键升级，不必再回到本页面下载。
