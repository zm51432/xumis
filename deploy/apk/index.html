shine 星心 · Android App

独立站官方移动客户端，接口已直连线上服务器。

  • 版本 1.2.0
  • Android 7.0+
  • 约 20 MB（含离线资源）
  • 接口：shine.xumois.cn
下载安装包（.apk）

如果微信内打不开，请点右上角「在浏览器中打开」

安装步骤

  1. 点击上面的按钮下载 shine-xumis.apk
  2. 在通知栏或文件管理里点开安装包
  3. 如提示「禁止安装未知来源应用」，按提示允许浏览器/文件管理器安装
  4. 打开 App，启动页显示「连接成功」即代表接口已打通

已内置的服务能力

  • 首页商品流、分类、搜索、排序（原生界面）
  • 商品详情：图片、价格、库存、材质、定制标识，支持分享与在浏览器打开
  • 购物车 / 下单 / 我的账户 / 来图定制（内嵌站点，与网页共用同一套账号与订单）
  • 「服务器设置」页可一键测试连接，显示服务名、数据库状态与接口耗时
  • 菜单 →「接口自检」：连续 50 次校验 ping / 商品 / 分类接口

1.2.0 新增：离线可用与可靠性自证

  • 内置离线商品册：12 件商品的图片、价格、材质、描述随包安装，断网也能浏览（约 13 MB 本地资源）
  • 离线兜底页：页面加载失败不再白屏，显示可重试的品牌页，并可跳转离线商品册 / 售后条款
  • 商品列表本地缓存：断网时自动展示上次缓存的商品，并标注缓存时间
  • 启动自动重试：弱网下重试 3 次（0.8s / 1.6s 退避）；仍失败可「离线进入」
  • 运行状态页：通过率、平均/最大延迟、缓存数量、离线资源、崩溃记录一屏可查
  • 帮助与关于：版本、连接状态、离线资源清单、常见问题、客服邮箱（离线可读）
  • 崩溃保护：异常自动留档并可回到启动页，不直接闪退
  • 内置字体：Nunito / Quicksand 6 款字重，离线排版不变形
服务器地址出厂即为 https://shine.xumois.cn，无需任何配置。 仅有本地调试时才需要在「服务器设置」里改成 http://10.0.2.2:8080（模拟器）或电脑内网地址。
