# 安卓客户端（APK）使用与发布说明 · shine星心

> 本文件说明 **shine星心 安卓客户端** 是什么、怎么下载安装、怎么连**你自己的服务器**、怎么做应用内升级。
> GitHub Releases 中发布的安装包固定命名为 **`shine.apk`**（当前 **1.5.0 / versionCode 6**）。
> 文档里的 `https://<你的域名>`、`http://<服务器IP>:8080` 都是占位符，请填你按《部署指南》自建的站点地址。

---

## 1. 客户端简介

- **名称**：shine星心 安卓客户端（ShineApp）
- **定位**：面向 shine星心 独立站后端（Spring Boot）的移动端 App，用于在手机上浏览商品、搜索、下单、查看订单。
- **技术**：Kotlin，ViewBinding，minSdk 24（Android 7.0），适配 Android 13（API 33）。
- **体积**：约 **20.4 MB**。
- **当前版本**：**1.5.0（versionCode 6）**，构建于 2026-10-30。
- **包名**：`com.shine.xumis.app`

> 说明：当前为**自签名**测试 / 分发包，尚未上架 Google Play 等应用商店，因此安装时系统会提示「风险应用 / 未知来源」，属正常现象。

---

## 2. 主要功能

- **启动页 Splash**：自动 `ping` 后端，连接成功进入主页，失败提示去「设置」改地址。
- **首页 Home**：原生商品网格（精选标记、图片、价格、分类），支持下拉刷新。
- **搜索 Search**：关键词 + 分类 + 排序（默认 / 价格升 / 价格降），原生结果列表。
- **商品详情 ProductDetail**：大图、价格、材质、库存、定制标；「去网页加购 / 购买」「查看购物车」一键跳站内流程。
- **购物车 Cart**：内嵌 WebView 加载站点 `/cart`，完整加购 / 结算 / 下单流程与网页一致。
- **我的 Account**：内嵌 WebView 加载站点 `/account`（登录 / 注册 / 订单 / 个人中心）。
- **设置 Settings**：填写服务器地址（含 `http://` 与端口）。
- **自检 Diagnostics（50 遍）**：对后端连续执行 50 次「健康检查 + 商品 / 分类接口校验」，实时显示每遍通过与失败计数，用于上架前 / 现场演示确认服务稳定。

### 对接的后端接口（`/api/m` 前缀）
| 接口 | 用途 |
|------|------|
| `GET /api/m/ping` | 健康检查探针 |
| `GET /api/m/products?page=&size=` | 商品分页列表 |
| `GET /api/m/products/{id}` | 商品详情 |
| `GET /api/m/categories` | 分类列表 |
| `GET /api/m/search?q=&cat=&sort=` | 搜索 / 分类 / 排序 |

> 后端接口默认不校验 `X-API-KEY`（开发期放行）；公网部署建议配置 `app.mobile-api-key` 并在 App 中带上。

## 3. 下载与安装

### 3.1 从 GitHub Releases 下载

1. 打开本仓库的 **Releases** 页面。
2. 在最新发布（标签 **`apk-v1.5.0`**）的 **Assets** 中找到 **`shine.apk`**，下载到手机（或先下到电脑再传到手机）。
3. 直接下载地址示例：
   ```
   https://github.com/zm51432/xumis/releases/download/apk-v1.5.0/shine.apk
   ```

### 3.2 安装（允许未知来源）

- **Android 8+**：下载完成后点开 APK，按提示「允许此次来源安装」，完成安装。
- 若系统阻止：进入 **设置 → 安全 → 安装未知应用**，对使用的浏览器 / 文件管理器授权后再装。
- 首次打开若提示「风险应用」，选择「继续安装」即可（未上架商店的自签名包，属正常提示）。

## 4. 首次使用：连接到你自己的服务器

App **不内置某个固定站点**，首次使用必须在「设置」里填写你的后端地址：

| 场景 | 服务器地址填写示例 |
|------|------------------|
| 模拟器（后端跑在电脑上） | `http://10.0.2.2:8080` |
| 真机同局域网 / 公网部署 | `https://<你的域名>` 或 `http://<服务器IP>:8080` |

填写后返回首页即可浏览、搜索、下单、查看订单。

> **重要**：这里的服务器地址**由你决定**，请填你按《部署指南》自建的站点地址；不要把它当成某个示例或他人的固定地址。

## 5. 应用内一键升级（OTA）

- 后端由 `deploy/ota/` 发布服务管理版本；当发布新版本，App 内会提示更新。
- **入口**：设置 → 关于 → 检查更新（可随时手动检查）。
- 升级包下载完成后**自动校验**签名 / 完整性，校验失败会给出具体原因提示。
- 升级**保留**登录态、购物车与离线商品册。
- **版本线**：1.4.0（基线，versionCode 5）→ 1.5.0（versionCode 6，新增 App 内一键升级、下载校验、关于页手动检查、保留状态）。

## 7. 自行编译（可选）

工具链：JDK 17 + Android SDK（`platform-tools`、`platforms;android-33`、`build-tools;33.0.2`）。

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=$HOME/Android/sdk
cd android
./gradlew assembleDebug          # 产物：app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest      # 核心逻辑单测（JSON 解析 / 价格 / 库存 / 自检）
```

更完整的说明见仓库内 `android/README.md`。

## 9. 常见问题

- **打不开 / 提示解析错误**：确认 Android 版本 ≥ 7.0（minSdk 24）。
- **首页空白 / 连不上**：检查「设置」里的服务器地址是否正确可达，先用该地址 `curl /api/m/ping` 验证后端存活。
- **升级失败**：多为下载不完整或签名不一致，重试即可；如仍失败，看 App 给出的具体提示。
- **安装被拦截**：在系统「安装未知应用」里对所用浏览器 / 文件管理器放行后再装。
