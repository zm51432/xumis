shine 星心 · Android App

独立站官方移动客户端，安装即用，无需任何配置。

  • 版本 1.5.0
  • Android 7.0+（含 14）
  • 约 20 MB（含离线资源）
  • 仅 4 项权限
  • 适配小米 / OPPO / vivo
下载安装包（.apk）

如果微信内打不开，请点右上角「在浏览器中打开」

安装步骤

  1. 点击上面的按钮下载 shine-xumis.apk
  2. 在通知栏或文件管理里点开安装包
  3. 如提示「禁止安装未知来源应用」，按提示允许浏览器/文件管理器安装
  4. 打开 App，启动页显示「连接成功」即代表接口已打通

已内置的服务能力

  • 首页商品流、分类、搜索、排序（原生界面）
  • 商品详情：图片、价格、库存、材质、定制标识，支持分享与在浏览器打开
  • 购物车 / 下单 / 我的账户 / 来图定制（内嵌站点，与网页共用同一套账号与订单）
  • 「设置」按常规 App 分组：通用 / 内容与存储 / 帮助与支持 / 关于，可调网页字号、检查网络、清理缓存
  • 设置 →「接口自检（50 次）」：连续校验 ping / 商品 / 分类接口

1.5.0 新增：App 内直接升级

  • 发现新版本自动提示：打开 App 时静默检查一次（6 小时内不重复），有新版即在应用内展示更新说明
  • 一键升级：点「立即更新」后原地下载安装包，进度可见，下载完成自动调起系统安装器
  • 安装包校验：下载完成按 SHA-256 比对服务端指纹，不一致立即删除，杜绝下载到损坏或被替换的包
  • 重要更新强制：服务端可把某个版本标为强制更新，客户端不接受「稍后再说」
  • 手动检查：设置 → 关于 → 检查更新，随时可查，结果显示当前是否为最新版
  • 升级不丢数据：登录状态、购物车、离线商品册与个人设置全部保留

1.4.0 新增：系统权限与品牌适配

  • 只申请四项权限：定位、手机相册、手机相机、蓝牙（外加联网）。通讯录、短信、通话记录、通知、后台定位等一概不申请
  • 权限管理页：设置 → 权限管理，四项权限各显示状态，可一键开启，并可就地验证（取坐标 / 数照片 / 试拍 / 扫蓝牙）
  • 按系统版本自动取权限：Android 12 拆分的蓝牙扫描/连接、Android 13 的图片权限、Android 14 的「仅选中的照片」都已覆盖
  • 适配小米 / OPPO / vivo：可一键跳转到各家的后台运行 / 自启动白名单页，避免被系统杀进程；硬件缺失的机型自动隐藏对应功能而不影响安装
  • 拍照上传打通：来图定制里可直接调用相机拍照上传，也能从厂商相册选择，拍完立刻回填预览
  • 拒绝也不影响使用：拒绝任一权限只关闭对应功能，并给出该品牌的具体开启路径

1.3.0 新增：设置改版

  • 界面不再出现服务器地址：App 在后台直连官方商店服务，安装即用，无需填写任何地址
  • 设置改为分组目录：通用（网页字号 / 检查网络 / 清除网页缓存）、内容与存储（离线商品缓存 / 离线资源）、帮助与支持（运行状态 / 接口自检 / 帮助与关于 / 配送与售后条款）、关于（版本 / 分享）
  • 网页字号可调：标准 / 大 / 特大三档，站内页面同步放大
  • 离线页更干净：断网兜底页、离线商品册、售后条款均不再显示任何网址
  • 右上角收敛为一个「设置」入口，其余功能全部归入设置目录

1.2.0 新增：离线可用与可靠性自证

  • 内置离线商品册：12 件商品的图片、价格、材质、描述随包安装，断网也能浏览（约 13 MB 本地资源）
  • 离线兜底页：页面加载失败不再白屏，显示可重试的品牌页，并可跳转离线商品册 / 售后条款
  • 商品列表本地缓存：断网时自动展示上次缓存的商品，并标注缓存时间
  • 启动自动重试：弱网下重试 3 次（0.8s / 1.6s 退避）；仍失败可「离线进入」
  • 运行状态页：通过率、平均/最大延迟、缓存数量、离线资源、崩溃记录一屏可查
  • 帮助与关于：版本、连接状态、离线资源清单、常见问题、客服邮箱（离线可读）
  • 崩溃保护：异常自动留档并可回到启动页，不直接闪退
  • 内置字体：Nunito / Quicksand 6 款字重，离线排版不变形
App 在后台直连官方商店服务，安装后不需要填写任何地址或账号信息。 权限可以随时拒绝，拒绝后只有对应功能不可用，商品浏览、搜索、下单等核心流程照常。
